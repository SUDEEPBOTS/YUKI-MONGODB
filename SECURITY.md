# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability within **YUKI-MONGODB**, please DO NOT create a public issue.

Instead, please send an email directly to the maintainer:
- Email: **sudeep@yukiapi.site** (or message via Telegram [@Sudeep](https://t.me/))

Please include:
1. Description of the vulnerability.
2. Steps to reproduce or proof-of-concept.
3. Affected components or environment.

We will acknowledge receipt within 48 hours and work with you on a swift resolution.
